# Back Ben for Mayor — rebuilt design system

This is a clean rebuild of the campaign prototype using the shared Joe Bloggs design language:
white/navy/bright-blue palette, Proxima Nova stack, photography-led heroes, compact header,
square buttons, flat cards, 3→2→1 responsive grids, light-blue personalised modules and consistent forms.

## Main files
- `assets/css/site.css` — global visual system
- `assets/js/site.js` — mobile navigation, demo forms and area personalisation
- `assets/data/areas.js` — area content configuration
- root HTML pages — campaign site
- `journeys/` — targeted campaign landing journeys
